## Qué hacemos

En Mictlán Labs diseñamos y desarrollamos aplicaciones web end‑to‑end: desde la interfaz y la experiencia, hasta APIs, datos y despliegues.
Nos gusta el software sencillo de mantener, rápido en producción y claro para colaborar.

**Principios**
- Performance primero (Core Web Vitals, payloads pequeños, cachés bien pensadas).
- Arquitectura pragmática (modularidad, separación de responsabilidades, testing donde aporta).
- Documentación y automatización (READMEs útiles, CI/CD, convenciones claras).

---

## Stack y enfoque

Tecnologías que usamos con frecuencia:
- Frontend: Astro, Next.js, React.
- Backend: NestJS, Node.js, TypeScript.
- Datos: PostgreSQL, Redis.
- Infra/DevOps: Docker, CI/CD, observabilidad.

Áreas donde solemos aportar valor:
- MVPs que salen rápido sin volverse frágiles.
- Refactors y mejoras de performance (frontend y API).
- Diseño de base de datos, optimización de queries y caché.
- APIs limpias (REST/GraphQL), autenticación (JWT/OAuth) y buenas prácticas.
